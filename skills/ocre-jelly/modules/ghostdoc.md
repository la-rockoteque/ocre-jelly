## GhostDoc (opinionated)
- Treat every GhostDoc summary as a draft. It echoes the name ("Gets the user name." on `GetUserName`). Rewrite it to say what the name doesn't, or delete it when docs aren't required.
- Remove `<autogeneratedoc />` and `// TODO Edit XML Comment Template for X` in the same edit that writes the real text. These are the only TODO markers ocre-jelly may delete.
- Keep the Microsoft phrasings GhostDoc gets right: "Initializes a new instance of the <see cref="T"/> class.", "Gets or sets", "Gets a value indicating whether".
- Replace GhostDoc's copied base-class text on overrides and interface members with `<inheritdoc/>`.
- Delete generated `<param>` text that only splits the name ("The user identifier." for `userId`) unless it adds a constraint.
