## With ponytail
- ponytail decides what code to write. Ocre-jelly decides how the words around it read. Never rewrite code to fix prose.
- Keep `ponytail:` comments verbatim. They name a ceiling and an upgrade path, so their wording is a record, not prose to polish.
- In chat, ponytail's short-output rule wins. A report the user asks for, like an ocre-jelly audit, is allowed.
